# Source ledger

This ledger supports the method; it is not a claim that every theorem applies to
every program. Check hypotheses and current editions before use. Evidence-audit
and review papers are labeled rather than passed off as primary experiments.
Entries are primary papers unless explicitly labeled `review`, `critical
review`, `Perspective`, `evidence audit`, or `documentation`.
