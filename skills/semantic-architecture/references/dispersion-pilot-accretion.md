is a roadmap, not a claim that every item is already implemented.

## Evidence that changed the reusable design

| Observation | Reusable consequence | Falsifier/success test |
|---|---|---|
| A declaration-only square initially appeared correspondence-ready | Separate structural readiness from artifact/execution binding | A declared square without a receipt must not promote correspondence |
| Oracle found the archive run was insufficiently bound to resolved inputs | Re-hash executable, input, and output bytes through a strict receipt | One changed input hash must return `binding_rejected` |
| The original EMA language covered 1,693 decisions while its eligible domain contained 1,687 | Make complete-corpus closure content-addressed and enumerable | Cardinality or eligibility-manifest mismatch must fail |
| The first state analyzer counted metadata changes as economic changes | Make intervention coordinates and semantic comparator explicit | A domain comparator must be hash-bound and reject an altered plan |
| An injected synthetic value was once described as broker observation | Bind source-correspondence claims to executed coordinate receipts | Synthetic or declaration-only evidence cannot promote observed correspondence |
| The split seam was Pareto-dominated by the current layout yet retained as a proof surface | Predeclare the delivery decision and selection rule | A post-hoc objective cannot justify an already selected candidate |
| A rank-boundary mutant produced a shortest two-action witness | Add finite challenge suites to Kerf | Nearby must-distinguish/must-preserve cases fail closed with shortest witnesses |
| Repeated corrected analyzers were byte-identical | Cache canonical campaign state and make unchanged reruns no-ops | Second invocation on identical state runs no expensive provider |

## Ranked roadmap

1. **Delivered here:** `kerf.execution-square-receipt.v1`, streaming artifact
   hashing, executable/argv binding, exact output comparison, minimal byte
   witness, split coordinate readiness, and a `kerf-pipeline verify-square`
   CLI. Dispersion lag 0 and lag 1 are the first real accepted consumers.
2. Add falsifier and coordinate-receipt references to a backward-compatible
   semantic-model evolution. Supported source correspondence must require an
   accepted bound square.
3. Add content-addressed corpus manifests with member identity, cardinality,
   enumerator/eligibility identity, parent corpus, and exhaustion receipt.
4. Add generic prospective challenge plans/results for negative controls,
   interventions, metamorphic relations, and finite mutants. Generalize the
   experiment shape, never trading-specific EMA or broker semantics.
5. Add a small content-addressed stage packet so semantic architecture, seam
   discovery, Kerf, and isomorphic refactoring cannot silently drop closure,
   counterexamples, or nonclaims.
6. Add a Kerf finite challenge-suite operation aggregating existing exact
   operations. Mutation score remains a harness diagnostic, never correctness.
7. Add decision contracts, complete dirty-source/build identity, qualified
   regression baselines, and declared evidence exposure policy.
8. Build `kerf-pipeline converge` only after these schemas have a second real
   consumer. Its success state is a decision or bounded-exhaustive fixed point;
   resource exhaustion preserves unknowns.

## Stop and reopen rule

Do not repeat the same multi-model or analyzer pass on the same source and
frontier. Reopen when source/build identity, decision contract, evidence,
corpus, provider, finite bound, or a decision-relevant falsifier changes. The
same source revision may merit another experiment; the same experiment frontier
should resolve by state hash without redoing expensive work.

For Dispersion specifically, the next high-information experiments are actual
live EMA initialization replay against the 16 lag-1 witnesses and full EMA60
plus alternative-portfolio replay. Historical broker correspondence cannot be
closed by another static pass because the required historical authority corpus
does not exist.
